Coral Cover turns your photos and a caption into multi-panel GTA-style poster cover art for the fictional city of Coral Bay, and exports it as a PNG in the common post sizes. It runs fully offline as static files: pick a layout, a colour grade and a size, position each photo, and export in one click.

## Run it

```sh
node serve.ts
```
